How the 3D view is made: every 4th generated frame is lifted with the depth predicted by WAMderer's auxiliary depth head and placed with WAMderer's own predicted camera. The depth head predicts relative depth, so its scale and shift are set once per traversal by Depth Anything 3 run on the same generated video; no ground truth is used. Results are precomputed.
